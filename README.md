# Amara Digital

A premium single-page website for **Amara Digital** — a Michigan-based growth
studio offering Meta Ads, web development, SEO, and AI automation.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Framer Motion (parallax, scroll splits, layout animations, counters)

## Run

```bash
npm install
npm run dev
```

Then open <http://localhost:5173>.

## Brand & design

- **Wordmark.** AMARA in Fraunces with a thin champagne-gold bar above —
  a modern nod to the Devanagari shirorekha (fits the South Asian root of
  "Amara", meaning timeless / eternal).
- **Palette.** Midnight (#0B0A09) + champagne gold (#D4B061) + ivory
  (#F2EAD7). No purple, no neon gradients — luxury positioning.
- **Type.** Fraunces (display, italic for accents) · Inter (body) ·
  JetBrains Mono (meta).
- **Motion.** Hero parallax, animated metric counters, sticky service
  spine that fills as you scroll, glassmorphic cards with hover lift,
  marquee, scroll-triggered word splits.

## Sections
