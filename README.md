# Consilting

A bespoke advisory site, built in India and serving everywhere.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Framer Motion (page transitions, scroll reveals, layout animations)
- React Router

## Run

```bash
npm install
npm run dev
```

Then open <http://localhost:5173>.

## Notes

- Brand: text-only wordmark inspired by the Devanagari **shirorekha** —
  the horizontal bar above letters in Hindi script.
- Palette: warm ivory + ink, with rust, marigold, indigo and peacock
  accents. Deliberately no purple, no AI gradients.
- Type: Fraunces (display) + Manrope (text) + JetBrains Mono (meta).
- Pricing isn't published — every engagement is tailored.
- Contact form collects name, email, company, role, industry, budget
  posture, preferred meeting date/time/timezone, and a free-form
  message. The "Schedule a meeting" CTA replaces "Book a free call"
  throughout.
